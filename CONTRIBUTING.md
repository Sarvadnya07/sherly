# Contributing to Sherly AI

We love your input! We want to make contributing to Sherly AI as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Becoming a maintainer

## Our Development Process

1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies** using `pip install .`.
3. **Write tests** for your changes in the `tests/` directory.
4. **Ensure tests pass** by running `pytest`.
5. **Lint your code** using `ruff check .`.
6. **Submit a Pull Request**.

## Pull Request Guidelines

- **Keep it focused**: One feature or bug fix per PR.
- **Update Documentation**: If you add a new tool or router, update the README and relevant docstrings.
- **Respect the Roadmap**: Check `FUTURE_SCOPE.md` before proposing major architectural shifts.

## Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all. Please be respectful and professional in all interactions.
